# 🛡️ CYBERSECURITY EXAM & PRETEST WEB APP

เว็บแอปพลิเคชันจำลองการสอบและฝึกทำข้อสอบวิชา **Cybersecurity** พัฒนาขึ้นโดยอ้างอิงจากคลังข้อสอบจริงทั้งหมด รวมกว่า **205 ข้อ**:
1. **📘 Pretest (25 ข้อ)**: อิงจากโฟลเดอร์ `pretest/` พร้อมการแปลเป็นภาษาไทยอย่างสมบูรณ์แบบ มีปุ่มสลับภาษาไทย / English / โหมดคู่ขนาน
2. **🎯 แนวข้อสอบ Final (22 ข้อ)**: อิงจากโฟลเดอร์ `แนวข้อสอบ/` ครบทุกข้อตามเฉลยจริง
3. **🧪 แนวข้อสอบแลป (10 ข้อ)**: อิงจากโฟลเดอร์ `แลป/` ข้อสอบแนวปฏิบัติการ (Hands-on, Nmap, Hashcat, ROT13, Linux UID, WMI, Windows Firewall, Metasploit)
4. **🌐 NCSA Pentest Labs (148 ข้อ)**: คลังข้อสอบจากระบบ NCSA MOOC Course 2 (PTES, Reconnaissance, Scanning, Exploitation, Privilege Escalation, Web Pentest, CTF Labs)
5. **🏆 Mock Exam (205 ข้อ)**: รวบรวมข้อสอบทั้งหมดสำหรับจำลองสอบเสมือนจริง

## 🚀 วิธีการเปิดใช้งาน (How to Run)

### วิธีที่ 1: เปิดบน iPhone / มือถือ
1. เชื่อมต่อ Wi-Fi เดียวกันกับเครื่องคอมพิวเตอร์
2. เปิด Safari หรือ Chrome บนมือถือ แล้วเข้าที่:
   ```
   http://192.168.1.102:3456
   ```
3. หรือเข้าผ่านลิงก์ออนไลน์ภายนอก (ผ่าน Localtunnel):
   ```
   https://thin-pigs-eat.loca.lt
   ```
   *(หากมีหน้าถาม Tunnel Password ให้ใส่: `27.130.117.45`)*
4. บน iPhone สามารถกด **"แชร์ (Share)" -> "เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)"** เพื่อใช้งานแบบเต็มหน้าจอเสมือน Native App ได้ทันที

### วิธีที่ 2: เปิดบนเครื่องคอมพิวเตอร์
- ดับเบิลคลิกเปิดไฟล์ `index.html` หรือเปิดผ่านเซิร์ฟเวอร์ที่: **http://localhost:3456**

## ✨ ฟีเจอร์เด่นของระบบ
- **⚡ โหมดฝึกฝน (Practice Mode):** แสดงผลคำตอบทันทีหลังเลือกช้อยส์หรือพิมพ์คำตอบ พร้อมเฉลยละเอียดและเจาะลึกหลักการทางเทคนิค
- **⏱️ โหมดสอบจริง (Exam Simulation):** มีตัวนับเวลาถอยหลัง (Timer), แผนผังข้อสอบ (Question Matrix), ระบบปักหมุดข้อที่สงสัย (Flag), บันทึกคำตอบแบบเรียลไทม์ และระบบคำนวณเกรด (S, A, B, C, F) พร้อมวิเคราะห์จุดแข็ง-จุดอ่อนแยกตามหมวดหมู่
- **🃏 โหมดแฟลชการ์ด (Flashcards):** การ์ด 3D พลิกกลับหน้า-หลังเพื่อทบทวนความจำอย่างรวดเร็วก่อนเข้าห้องสอบ
- **📱 Mobile & iPhone Optimized:** ออกแบบรองรับ Safe Area (Notch / Dynamic Island), เมนูเลื่อนแนวนอนแบบสัมผัส (Swipeable tabs), ป้องกันการซูมฟอนต์บน Safari, และรองรับการพิมพ์ตอบ Flag/คำสั่งอย่างลื่นไหล
- **🔊 Web Audio API Synthesizer:** เสียงเอฟเฟกต์สังเคราะห์ในตัว ไม่ต้องโหลดไฟล์เสียงภายนอก
- **⌨️ Keyboard Shortcuts (Desktop):**
  - `1`, `2`, `3`, `4`: เลือกช้อยส์ A, B, C, D
  - `ลูกศรซ้าย` / `ลูกศรขวา`: เปลี่ยนข้อ
  - `F`: ปักหมุด
  - `Spacebar`: พลิกแฟลชการ์ด
  - `Enter`: ตรวจคำตอบ / บันทึกคำตอบ
